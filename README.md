# 🍅 懲罰者番茄鐘 (Punishing Pomodoro)

## 📖 專案簡介
這是一個基於 STM32G474RE 微控制器的「硬派」番茄鐘系統。與傳統溫和的番茄鐘不同，本系統導入了「懲罰機制」。當休息時間結束後，使用者必須在短暫的「寬限期 (Grace Period)」內按下按鈕確認回到工作崗位。若超時未回應，系統將進入「懲罰模式 (Punish Mode)」，觸發高頻警報與爆閃燈效，強制終結你的拖延症！

## 🛠️ 硬體腳位配置
* **PA5 (PWM 輸出)**：連接 LED，呈現深呼吸燈 (專注)、輕快雙閃 (休息)、慢閃 (寬限期) 與 極速爆閃 (懲罰)。
* **PC13 (外部中斷)**：藍色實體按鈕 (B1)，用於解除懲罰、略過休息或暫停計時。
* **PB6 (PWM 輸出)**：連接蜂鳴器，發出不同頻率的提示音與刺耳警報。
* **PA2 / PA3 (USART2)**：用於與電腦端 (如 PuTTY) 進行字串指令傳輸與狀態回報。

## ⚙️ 核心狀態機與燈效 (FSM)
本系統共有 5 種狀態自動切換：
1. **STATE_IDLE (待機)**：燈光全滅，等待開始指令。
2. **STATE_FOCUS (專注)**：進行 25 分鐘倒數，LED 呈現平滑呼吸燈。
3. **STATE_BREAK (休息)**：進行 5 分鐘倒數，LED 呈輕快雙閃，蜂鳴器短嗶提示。
4. **STATE_GRACE (寬限期)**：休息結束後的 5 秒緩衝時間，LED 慢閃，等待使用者按鈕。
5. **STATE_PUNISH (懲罰)**：寬限期內未按按鈕觸發。LED 極速爆閃，蜂鳴器交替發出 2kHz/3.5kHz 刺耳警報。

## 💻 UART 控制指令
透過電腦端序列埠軟體 (Baud Rate: 115200 8N1) 輸入以下指令控制：
* `START`：啟動 25 分鐘專注模式。
* `STOP`：強制停止，回到待機模式。
* `PAUSE`：暫停/恢復當前倒數，燈效凍結。
* `TEST`：進入快速展示模式 (5秒專注 -> 5秒休息 -> 5秒寬限期 -> 懲罰)。
